# Engine port regression tests

Build the native extension before running the tests:

```sh
python src/build.py
PYTHONPATH=src python -m unittest discover -s src/tests -p '*_test.py' -v
MYPYPATH=src python -m mypy --explicit-package-bases src
```

The tests need NumPy, CPU PyTorch, CMake (the `cmake` Python package), and a C++ compiler,
but do not require a trained model or CUDA.
They follow the layout of DeepShogi's `src/tests/` with comments translated into English.
Upstream tests that depend on game records (`src/tests/records/`), cshogi, the model definitions,
the training code, or the CSA client are not ported.

## Layout

| File | Contents |
|------|----------|
| `board_test.py` | Native board reinitialization. |
| `compile_test.py` | Preparing fixed-batch models from dynamic-batch ExportedPrograms, precision conversion, AOTInductor compilation, and Gokaku-specific device, backend, metadata, and file handling checks. |
| `fileutil_test.py` | Moving temporary files to their destinations on the same and different file systems without leaving partial files. |
| `inference_test.py` | Input layout, fixed-batch splitting and padding, loading ExportedPrograms and PT2 packages, the C++ inference cache test, and the threaded search and USI lifecycle in subprocesses. |
| `player_test.py` | Referee perpetual checks, search termination, search extensions, random move selection, Python stop handling, and native Player regressions including the C++ Player test. |
| `pnsearch_test.py` | C++ PN search and DF-PN tests, the DF-PN benchmark, and Python PN search regressions using positions extracted from upstream records 001 through 004. |
| `psfen_test.py` | Packed SFEN conversion of multi-digit hand counts. |
| `settings_test.py` | CLI, USI, Python, Cython, and C++ setting validation, PT2 device selection, lazy model loading at `isready`, and processor initialization failures. |
| `usi_test.py` | Lazy processor creation, time allocation, asynchronous commands, and USI responses. |
| `native.py` | Builds the C++ tests with CMake and runs them (`run_native_test`). |
| `native/` | C++ tests and their `CMakeLists.txt`. |
| `probe_model.py` | Small probe models and helpers that export them as ExportedPrograms and compile them into CPU PT2 packages. |
| `search_worker.py`, `usi_worker.py` | Subprocess workers used by `inference_test.py`. |

## C++ tests

The C++ tests in `native/` are built and run automatically by the Python tests through
`native.py`. The build uses a temporary directory and the `Config.h` generated by
`python src/build.py`.

| Target | Contents | Called from |
|--------|----------|-------------|
| `player_wait_native_test` | Player waits, shutdown, exception cleanup, mate limits, repetitions, perpetual checks, nyugyoku scores, PN search aborts, and PUCB (links LibTorch and uses a CPU PT2 model) | `player_test.py` |
| `pnsearch_native_test` | PN search node management, caches, and loop handling | `pnsearch_test.py` |
| `pnsearch_abort_native_test` | PN search aborts, board restoration, and engine reuse | `pnsearch_test.py` |
| `pnsearch_cache_native_test` | PN search cache collisions and generation updates | `pnsearch_test.py` |
| `pnsearch_moves_native_test` | Legal move storage, node cloning, and repetition handling | `pnsearch_test.py` |
| `dfpn_native_test` | DF-PN thresholds, progress correction, and loop cloning | `pnsearch_test.py` |
| `dfpn_benchmark` | DF-PN benchmark over an SFEN file | `pnsearch_test.py` |
| `inference_cache_test` | Inference cache eviction and rule-dependent keys, and PN cache collisions | `inference_test.py` |

CUDA, FP16 on CUDA, TensorRT, and trained-model playing strength require separate environment
checks.
